# SPA-Trecks — Офлайн-аналізатор GPS-треків

![Версія](https://img.shields.io/badge/версія-1.1.0-blue)
![Ліцензія](https://img.shields.io/badge/ліцензія-MIT-green)
![JS](https://img.shields.io/badge/JavaScript-ES2022+-yellow)

**SPA-Trecks** — це повністю клієнтський аналізатор GPS-треків, що працює безпосередньо у браузері. Завантажте файли GPX, TCX або KML — і миттєво отримайте візуалізацію маршруту з тепловою картою швидкості, синхронізованими графіками, анімацією проходу та детальною статистикою. Жодних серверних компонентів, жодного кроку збирання — лише статичні файли та сучасний браузер.

---

## Можливості

- **Завантаження кількох треків** — додавайте файли GPX/TCX/KML через панель праворуч. Натисніть «+ Додати файли», щоб обрати файли з диска.
- **Управління видимістю** — кожен завантажений трек має прапорець. Зніміть його, щоб приховати трек на карті; трек залишиться завантаженим.
- **Вибір основного треку** — натисніть на назву треку у списку, щоб зробити його основним (виділено золотим). Основний трек отримує розфарбування за швидкістю/висотою/пульсом, анімацію проходу, графіки та статистику. Інші треки відображаються своїм суцільним кольором.
- **Видалення треків** — натисніть ×, щоб видалити трек із поточної сесії.
- **Теплова карта за швидкістю** — маршрут розфарбовується за швидкістю (зелений — повільно, червоний — швидко), висотою або пульсом. Використовується HSL-градієнт із 32 кольоровими сегментами.
- **Синхронізовані графіки Chart.js** — графіки швидкості, висоти та пульсу синхронізовані з анімацією проходу на карті.
- **Анімований прохід маршруту** — відтворення/пауза анімації з маркером, що рухається вздовж маршруту. HUD телеметрії в реальному часі: швидкість, пульс, висота, час.
- **Статистика маршруту** — відстань, тривалість, середня/максимальна швидкість, набір/втрата висоти, середній/максимальний пульс, кількість точок, час початку та завершення.
- **Підказки** — наведіть курсор на маршрут, щоб побачити деталі точки: швидкість, висоту, пульс, час, відстань, координати.
- **Експорт даних** — експорт основного треку у форматах CSV, JSON або GPX.
- **Мобільна підтримка** — сенсорні жести через Hammer.js: свайп для зміни режиму, подвійне торкання для відтворення/паузи.
- **Корекція дрейфу висот** — згладжування даних висоти та виправлення дрейфу на початку/кінці маршруту.
- **Повноекранний режим** — натисніть F для переходу в повноекранний режим.
- **Згортання панелі треків** — натисніть ▼/▶, щоб згорнути або розгорнути панель керування треками.

## Клавіатурні комбінації

| Клавіша | Дія |
|---------|-----|
| **S** | Режим швидкості (розфарбування за швидкістю) |
| **H** | Режим висоти (розфарбування за висотою) |
| **P** | Режим пульсу (розфарбування за пульсом) |
| **G** | Показати/приховати панель графіків |
| **T** | Показати/приховати накладення статистики |
| **Пробіл** | Відтворення / Пауза анімації |
| **←** | Крок назад |
| **→** | Крок уперед |
| **X** | Експорт у CSV |
| **Z** | Експорт у JSON |
| **E** | Експорт у GPX |
| **F** | Повноекранний режим |
| **C** | Застосувати корекцію дрейфу висот |

## Встановлення та запуск

Проєкт не потребує збирання, залежностей чи пакетного менеджера. Потрібен лише статичний файловий сервер та сучасний браузер.

1. **Клонуйте репозиторій:**
   ```bash
   git clone https://github.com/Antigravity/SPA-Trecks.git
   ```

2. **Перейдіть до каталогу проєкту:**
   ```bash
   cd SPA-Trecks
   ```

3. **Запустіть статичний файловий сервер.** Будь-який із наведених варіантів:
   ```bash
   # Python
   python3 -m http.server 8000

   # Node.js
   npx serve .

   # Або використовуйте розширення Live Server у VS Code
   ```

4. **Відкрийте у браузері:**
   ```
   http://localhost:8000
   ```

5. **Завантажте треки** — натисніть «+ Додати файли» у панелі праворуч угорі та оберіть файли GPX, TCX або KML.

> **Увага:** проєкт не працює при відкритті безпосередньо через протокол `file://`. Обов'язковий запуск через статичний сервер.

├── index.html              # Головна HTML-сторінка
├── app.js                  # Оркестратор додатку
├── style.css               # Усі стилі
├── modules/

│   ├── ui.js               # Клавіатурне керування та кнопки
│   ├── drift.js            # Згладжування висот та корекція дрейфу
│   └── mobile.js           # Сенсорні жести (Hammer.js)
├── LICENSE                 # Ліцензія MIT

- Chrome 61+
- Firefox 60+
- Safari 11+
- Edge 79+

Для початкового завантаження бібліотек з CDN (Leaflet, Chart.js, Hammer.js) потрібне з'єднання з інтернетом. Після цього для завантаження картографічних тайлів також потрібен інтернет.
