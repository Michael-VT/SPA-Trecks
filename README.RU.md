# SPA-Trecks — Офлайн-анализатор GPS-треков

![Версия](https://img.shields.io/badge/версия-1.1.0-blue)
![Лицензия](https://img.shields.io/badge/лицензия-MIT-green)

**SPA-Trecks** — это легковесное браузерное приложение для визуализации и анализа GPS-треков. Оно работает полностью на стороне клиента, не требует сборки и установки зависимостей — достаточно открыть страницу через локальный сервер. Приложение поддерживает загрузку файлов в форматах GPX, TCX и KML, отображает маршруты на карте с тепловой раскраской по скорости, высоте или пульсу, строит синхронизированные графики и воспроизводит анимацию прохождения трека.

## Возможности

1. **Многотрековая загрузка** — добавляйте несколько файлов GPX/TCX/KML через панель справа. Нажмите «+ Добавить файлы», чтобы выбрать файлы с диска.
2. **Управление видимостью треков** — каждый загруженный трек имеет флажок: отметьте или снимите его, чтобы показать или скрыть трек на карте. Скрытые треки остаются загруженными в сессии.
3. **Выбор основного трека** — кликните по названию трека в списке, чтобы сделать его основным (выделяется золотым цветом). Основной трек получает тепловую раскраску, анимацию воспроизведения, графики и статистику. Остальные треки отображаются сплошным цветом.
4. **Удаление треков** — нажмите кнопку ×, чтобы удалить трек из текущей сессии.
5. **Цветовая тепловая карта** — маршруты раскрашиваются по скорости (зелёный = медленно → красный = быстро), высоте или пульсу с использованием HSL-градиента и 32 цветовых сегментов.
6. **Синхронизированные графики Chart.js** — графики скорости, высоты и пульса синхронизированы с анимацией воспроизведения на карте.
7. **Анимированное воспроизведение** — воспроизведение и пауза анимации с движущимся маркером вдоль маршрута. Отображение телеметрии в реальном времени: скорость, пульс, высота и время.
8. **Статистика маршрута** — расстояние, продолжительность, средняя и максимальная скорость, набор и потеря высоты, средний и максимальный пульс, количество точек, время начала и окончания.
9. **Подсказки при наведении** — наведите курсор на маршрут, чтобы увидеть подробную информацию о точке: скорость, высота, пульс, время, расстояние и координаты.
10. **Экспорт данных** — экспорт основного трека в форматах CSV, JSON или GPX.
11. **Мобильная поддержка** — сенсорные жесты через Hammer.js (свайп для смены режима, двойное нажатие для воспроизведения/паузы).
12. **Коррекция дрейфа высоты** — сглаживание данных о высоте и исправление дрейфа между начальной и конечной точками.
13. **Полноэкранный режим** — нажмите F для перехода в полноэкранный режим.
14. **Сворачиваемая панель треков** — нажмите ▼/▶, чтобы свернуть или развернуть панель управления треками.

## Управление с клавиатуры

| Клавиша | Действие |
|---------|----------|
| **S** | Режим скорости (раскраска по скорости) |
| **H** | Режим высоты (раскраска по высоте) |
| **P** | Режим пульса (раскраска по пульсу) |
| **G** | Показать/скрыть панель графиков |
| **T** | Показать/скрыть статистику |
| **Пробел** | Воспроизведение / Пауза |
| **← / →** | Шаг назад / Шаг вперёд |
| **X** | Экспорт в CSV |
| **Z** | Экспорт в JSON |
| **E** | Экспорт в GPX |
| **F** | Полноэкранный режим |
| **C** | Применить коррекцию дрейфа высоты |

## Сенсорное управление (мобильные устройства)

| Жест | Действие |
|------|----------|
| Свайп влево / вправо | Переключение режима (скорость / высота) |
| Свайп вверх | Открыть панель графиков |
| Свайп вниз | Закрыть панель графиков |
| Двойное нажатие | Воспроизведение / Пауза |
| Долгое нажатие | Отладочный вывод |

## Установка и запуск

Для работы приложения не требуется сборка, установка npm-зависимостей или каких-либо дополнительных инструментов. Достаточно клонировать репозиторий и запустить любой статический файловый сервер.

```bash
# 1. Клонируйте репозиторий
git clone https://github.com/Antigravity/SPA-Trecks.git

# 2. Перейдите в папку проекта
cd SPA-Trecks

# 3. Запустите статический сервер (один из вариантов)
python3 -m http.server 8000
# или
npx serve .
# или используйте расширение Live Server в VS Code
```

Откройте `http://localhost:8000` в браузере. Нажмите «+ Добавить файлы» на панели справа, чтобы загрузить GPS-треки.

> **Важно:** приложение не работает при открытии через протокол `file://` — необходим сервер.

## Системные требования

Современный браузер с поддержкой ES-модулей: Chrome 61+, Firefox 60+, Safari 11+, Edge 79+.

Для начальной загрузки библиотек с CDN (Leaflet, Chart.js, Hammer.js) требуется подключение к интернету. После загрузки тайлы карты по-прежнему требуют интернет-соединения.
